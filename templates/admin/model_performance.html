{% if has_screening %}
Two cut-offs, on purpose. The Accuracy / Precision / Recall columns use the textbook 0.50 cut-off so the numbers stay comparable with published results. The application itself decides “at risk” at {{ '%.2f'|format(screen_threshold) }} (Config.POSITIVE_THRESHOLD) — a deliberately lower screening threshold, because missing a real case costs more than an unnecessary check-up. The Recall @{{ '%.2f'|format(screen_threshold) }} column shows how many true cases that catches.
{% endif %} {% if calibration %}
Calibration — is a predicted 72% really a 72%?
Patients are binned by predicted probability; each point compares the bin’s average prediction (x) with the fraction who actually have the disease (y). A trustworthy model hugs the dotted diagonal. The Brier score in the table above summarises the same idea as one number — lower is better.
{% endif %}

The scaler is refitted inside every fold and the held-out test set is excluded, so these figures carry no information leakage. A small standard deviation means the model does not depend on which particular split it was given.
